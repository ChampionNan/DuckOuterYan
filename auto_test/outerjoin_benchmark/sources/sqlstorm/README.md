# SQLStorm source queries

These 12 SQL files are unmodified source-query records used to derive the
SQLStorm stratum of the OuterJoin benchmark. They were copied from SQLStorm
v1.0 at commit `b3bb0b96794a6afe9bb8f3ff2b243562b779c40d`:

- upstream repository: <https://github.com/SQL-Storm/SQLStorm>
- upstream path: `v1.0/{tpch,tpcds,job}/queries/`

The benchmark manifest records the selected upstream query identifier and the
SHA-256 hash of each local copy. The local SQL is retained so benchmark
generation and provenance verification do not require network access. See
`LICENSE` in this directory for the upstream license.
